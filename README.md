# Daily Python Logic Questions

A collection of Python practice problems and logic-building exercises designed to improve problem-solving, fundamentals, and object-oriented programming skills.

## Overview

This repository contains daily Python logic questions with hands-on examples covering:

- Basic arithmetic and logic operations
- String and list manipulation
- Control flow and loops
- Object-oriented programming concepts
- Custom data structures and operators
- Small algorithmic problem-solving challenges

## Example

The repository includes custom datatype examples such as a `Fraction` class with overloaded arithmetic operators:

```python
x = Fraction(4, 5)
y = Fraction(2, 3)

print(x + y)
print(x - y)
print(x * y)
print(x / y)
```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/premsen2703-prog/daily-python-logic-questions.git
cd daily-python-logic-questions
```

2. Run any Python file:

```bash
python OOPS_python/custom_datatype/custom_dataypte.py
```
